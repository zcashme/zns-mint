# librustzcash Documentation

This directory contains standardized documentation and patterns extracted from the `librustzcash` repository. It is intended to help coding agents and developers effectively understand and utilize the `librustzcash` monorepo for Zcash blockchain development.

## Contents

1. [Architecture and Crates](./architecture_and_crates.md) - Overview of the workspace structure, crate layering, and dependencies.
2. [Coding Patterns](./coding_patterns.md) - Key abstractions, trait designs, and protocol transaction flows.
3. [Git Patterns](./git_patterns.md) - Conventions for commits, branches, and PRs used by the `librustzcash` team.
